# NSU Course Advising Rules

- When the student asks about course planning, routines, or NSU advising, use the tools from the `nsu-planner` MCP server.
- Default to the current active semester (`Fall 2026`) unless the user explicitly requests another term.
- When generating routines, ALWAYS format each routine using the **Weekly Timetable Grid** structure:
  - First column: `Time Slot` (e.g. `08:00 AM - 09:30 AM`, `09:40 AM - 11:10 AM`, `11:20 AM - 12:50 PM`, `01:00 PM - 02:30 PM`, `02:40 PM - 04:10 PM`, `04:20 PM - 05:50 PM`).
  - Day columns: `Sunday`, `Monday`, `Tuesday`, `Wednesday`, `Thursday` as table headers.
  - Cells: Place courses in their exact time slot and day (`**COURSE (Sec X)**<br>FACULTY · ROOM`), using `—` for empty slots. Ensure all times and days align properly.
- Always include a **Key Highlights** bullet list for each routine option (highlighting class distribution, gaps, breaks, and open seat availability).
- **DO NOT** include the Final Exam Distribution / Load Assessment section in routine responses (omit it unless explicitly requested by the student).
