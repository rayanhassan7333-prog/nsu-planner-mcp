# NSU Advising Planner Plugin for Antigravity

Smart course advising and routine generation assistant for North South University (NSU) students.

## What is Included:
- **Skill**: `nsu-advising` (Advising domain knowledge, timeslots, and final exam odd/even slot rules).
- **MCP Server**: `nsu-planner` (Local high-performance stdio solver with 10,500+ NSU course records).
- **Rules**: `rules/AGENTS.md` (Active guidelines for all planning and advising conversations).
- **Branding**: Official NSU Advising Planner logo.
